# NAGHEDI Immigration – Hugo

Hugo implementation of the NAGHEDI immigration site, reusing Squarespace CSS.

## Setup

**Prerequisite:** Hugo must be installed (it is not bundled via npm). On macOS:

```bash
brew install hugo
```

Verify: `hugo version`

## Build & dev

```bash
pnpm build   # → public/
pnpm dev     # → http://localhost:1313
```
